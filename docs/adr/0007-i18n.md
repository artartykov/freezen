# ADR-0007: Internationalization

- accepted - 2026-11-17

## Decision

- Ship English and Russian. At startup, pick the first supported device or browser language (`ru-RU` → `ru`). Fall back to English. Defer manual selection.
- Group user-facing strings and plural forms by area in `shared`.
- Use the active locale for `Intl` date and number formatting and document `lang`.
- Keep i18n independent of Tauri. Use a platform adapter for Android APIs if needed.
