# ADR-0000: Architecture Decision Records

- accepted - 2026-11-16

## Decision

Accepted ADRs are not rewritten. If a decision no longer applies, append a `withdrawn` entry with its date to the status history. Keep entries in chronological order and preserve earlier entries. Record any replacement decision in a new ADR.

Example:

```text
- accepted - 2026-11-16
- withdrawn - 2026-11-25
```
