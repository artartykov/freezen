# ADR-0003: Frontend Stack

- accepted - 2026-11-16

## Context

FreeZen is a relatively simple app. The frontend stack should match that scope and build on existing experience with React.

## Decision

- Use Vite for frontend development and builds; the app's scope does not require a more complex framework.
- Use TypeScript for static typing and safer refactoring.
- Use React for the UI because it is the most familiar option.
